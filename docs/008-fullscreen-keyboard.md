**フェーズ:** v1.0

**依存:** 007

## 概要

学習画面にイマーシブな全画面モードを追加する。ステータスバー・ナビゲーションバーを非表示にし、Bluetooth キーボードでのカード操作に対応する。

### Bluetooth キーボード操作
- [ ] キーボードイベント検知（`react-native-keyevent` or カスタムフック）
- [ ] キーマッピング実装:
  - [ ] `Space` — 表→裏の切替
  - [ ] `→`（右矢印）— 次のカードへ
  - [ ] `←`（左矢印）— 前のカードへ
  - [ ] `1` — 自己評価「もう一度」
  - [ ] `2` — 自己評価「難しい」
  - [ ] `3` — 自己評価「普通」
  - [ ] `4` — 自己評価「簡単」
  - [ ] `M` — メモの表示/非表示
  - [ ] `R` — コード実行（009 実装後）
  - [ ] `Escape` — 全画面モード終了

## 技術メモ

- iOS では `TVEventHandler` or `KeyboardAvoidingView` での検知を調査
- Android では `react-native-keyevent` が有効
- 全画面モードの状態は `useStudySession` フックに保持
