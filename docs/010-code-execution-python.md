## 概要

## 技術メモ

- Pyodide はサイズが大きい（~10MB）のでバンドル方法を慎重に選択
- 初回ロードに数秒かかる可能性あり → バックグラウンドプリロード
- 009 の WebView サンドボックスを拡張して使用
