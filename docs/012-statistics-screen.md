## 技術メモ

- チャートは軽量なライブラリを選択（`react-native-chart-kit` 等）または SVG 自作
- 統計データは `reviews` テーブルから集計
- ストリーク計算: `lastReviewDate` の連続日数をカウント

### 学習カレンダー（草グラフ）

- `components/stats/ActivityHeatmap.tsx` で実装
- データソース: `review_logs` テーブルを日別集計（`getDailyReviewCounts`）
- 表示期間: 全端末共通で **52週（約1年）固定**、stats.tsx で `52 * 7` 日分を取得
- セルサイズ: 11px、ギャップ: 2px、曜日列幅: 20px
- 色の閾値: 0件=グレー / 1〜3件=薄緑 / 4〜9件=中緑 / 10件以上=濃緑
- 曜日ラベル（月〜日）は ScrollView 外に固定し、横スクロール時も常に表示
- 月ラベルはセルグリッドと一緒にスクロール（月初日の列に `position: absolute` で配置）
- 起動時・週数変更時に `scrollToEnd` で最新日（右端）へ自動スクロール
- 将来対応: ハイブリッドスクロール（画面幅いっぱい表示 ＋ 左スクロールで全履歴を遡る）

### セクション折りたたみ（2026-07-12 追記）

セクション増加（棒グラフ／学習履歴／今日のサマリー／全体学習率／デッキ別習熟度／詳細統計 Pro の6つ）による縦長化対策として、セクション単位の折りたたみを追加。

- **操作**: セクションタイトル行タップでトグル。タイトル右端に chevron（開: `chevron-down` / 閉: `chevron-forward`）。`settings/sync.tsx` の既存アコーディオンと同じ文法（条件レンダリング・アニメーションなし）。ⓘ は独立ボタンのまま
- **対象**: 6セクション全部。上部4ブロック（連続/済み/復習/新規）は常設
- **永続化**: `useSettingsStore.statsCollapsedSections: string[]`（`gradeRankingDeckIds` と同じ JSON 方式・`lib/settings-keys.ts` 登録済み）
- **キーボード**: 折りたたみ中セクションの行（heatmap/today/total/deck）は J/K の focusList から除外
- **見送った案**: デッキ別習熟度の個別折りたたみ（アーカイブ機能と役割重複）・デッキ絞り込みアイコン・上位N件＋もっと見る（デッキが多くて困ったら後付け候補）・折りたたみ専用キー（フォーカス単位が行でありセクションでないため v1 見送り）
