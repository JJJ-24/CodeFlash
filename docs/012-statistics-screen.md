## 技術メモ

- チャートは軽量なライブラリを選択（`react-native-chart-kit` 等）または SVG 自作
- 統計データは `reviews` テーブルから集計
- ストリーク計算: `lastReviewDate` の連続日数をカウント

### 学習カレンダー（草グラフ）

- `components/stats/ActivityHeatmap.tsx` で実装
- データソース: `review_logs` テーブルを日別集計（`getDailyReviewCounts`）
- 表示期間: 全端末共通で **52週（約1年）固定**、stats.tsx で `52 * 7` 日分を取得
- セルサイズ: 11px、ギャップ: 2px、曜日列幅: 20px
- 色の閾値: 0件=グレー / 1〜3件=薄緑 / 4〜9件=中緑 / 10件以上=濃緑
- 曜日ラベル（月〜日）は ScrollView 外に固定し、横スクロール時も常に表示
- 月ラベルはセルグリッドと一緒にスクロール（月初日の列に `position: absolute` で配置）
- 起動時・週数変更時に `scrollToEnd` で最新日（右端）へ自動スクロール
- 将来対応: ハイブリッドスクロール（画面幅いっぱい表示 ＋ 左スクロールで全履歴を遡る）
