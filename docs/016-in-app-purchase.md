## 価格戦略・リリース方針（2026-05-13 決定）

### v1.0 リリース時の Pro 機能

- **詳細な学習統計**（チケット024で実装済み）を起点に先行リリース
- FSRS カスタマイズ（チケット025）は v1.0 に含める可能性あり（実装次第で判断）
- iCloud 同期・AI生成・SQL/C++ 実行・Web版は次バージョン以降で順次追加
- iCloud 同期はライブラリ成熟度・実装コストを考慮し v1.1 以降に延期（現状の JSON エクスポート/インポート機能で代替可能）

### 価格戦略

買い切りアプリの定石「機能追加時に値上げ」を採用。既存購入者は追加課金なしで新機能を利用可能。

> ⚠️ **以下の価格テーブルはあくまで仮の例**。実際の値上げ判断（タイミング・金額・対象機能）はその都度検討する。FSRS カスタマイズも v1.0 に含める可能性あり。

| バージョン | 通常価格（仮） | 主な追加機能                   |
| ---------- | -------------- | ------------------------------ |
| v1.0       | ¥1,480         | 詳細な学習統計（初回リリース） |
| v1.1       | ¥1,980         | iCloud 同期                    |
| v1.2       | ¥2,480         | FSRS カスタマイズ              |
| v2.0       | ¥2,980         | AI カード自動生成              |

### ローンチセール

- リリース後 **1週間** だけ **¥980**（App Store Connect の Price Schedule で設定）
- 2週間目以降は通常価格 ¥1,480 に戻す
- 初動レビュー獲得・App Store セールフィード露出を狙う

### 値上げ運用ルール（方針案）

- 通常価格を最初から ¥1,480 として設定（値上げ感を抑える）
- 競合（年5,000円サブスク）と比較し、買い切り3〜5年分相当の価値を訴求
- 値上げは新機能リリースと同時に実施し「今買えば追加機能も無料で使える」訴求を作る方針だが、**どのバージョンで値上げするかはその都度検討**（毎回上げるとは限らない）
