## 画像対応エクスポート/インポート

現状の実装では画像ブロックの `uri`（`local://images/xxx.jpg`）はパス文字列のみ保存されており、
画像ファイル本体はエクスポートに含まれない。そのため別端末へのインポートや、
画像削除後の復元ができない。以下の機能を追加実装する。

### Todo

- [x] **Base64埋め込み対応**: エクスポート時に画像ファイルを読み込みBase64文字列としてJSONに含める。インポート時はBase64をデコードして `images/` ディレクトリにファイルとして書き出す。
- [x] **画像含む/含まない選択UI**: エクスポート実行時に「画像を含める（完全バックアップ）／含めない（軽量バックアップ）」を選択できるようにする。「含めない」を選んだ場合は別端末では画像が表示されない旨を警告する。
- [x] **大容量警告**: 画像を含めてエクスポートする際、推定ファイルサイズに応じて2段階の確認ダイアログを表示する。
  - 10MB超〜50MB以下: 「約○MBになります。続けますか？」
  - 50MB超: 「約○MBになります。レスポンスに影響が出る可能性があります。続けますか？」

### 設計メモ
- Base64はバイナリの約1.33倍のサイズになる。1枚5MB上限のため1枚あたり最大約6.7MB相当。
- SQLiteには引き続きパス文字列のみ保存する（Base64をDBに入れない）。
- エクスポートJSONの `ExportData` に `imageData?: Record<string, string>`（キー: ファイル名、値: Base64）フィールドを追加する形が考えられる。

### 将来検討: デッキ別エクスポート

タグは複数デッキをまたいで共有されるため、選択デッキで使われているタグのみ含める判断が必要。

## TSVエクスポート/インポート（実装済み）

Anki・Excel・Numbers との連携を目的としたTSV（タブ区切り）形式の入出力機能。

### ファイル形式

```
id	front	back	memo
card_id_1	表面テキスト	裏面テキスト	メモテキスト
card_id_2	...	...	...
```

- 1列目: カードID（本アプリのエクスポートのみ付与）
- セル内改行は `\n`、タブは `\t` にエスケープして保持

### インポートの照合ロジック

| TSVの列構成 | 照合方法 | 結果 |
|---|---|---|
| `id\tfront\tback\tmemo`（本アプリ出力） | カードIDで照合 | ID一致 → 上書き、IDなし/未存在 → 新規作成 |
| `front\tback\tmemo` or ヘッダーなし（Anki・手作り） | 照合なし | 常に新規作成 |

### ブロック変換ルール
- **エクスポート**: 全ブロックのテキスト内容を `\n` で結合。ImageBlock は `[image]` として出力
- **インポート**: 各セルを `TextBlock` 1つに変換（コードブロック・画像は復元不可）

### 制約・注意
- 学習履歴（SM-2データ）はTSVに含まれない。インポート後は未学習状態
- Excelで編集する際は `id` 列を削除しないこと（削除すると上書きではなく新規作成になる）
- コードブロック・画像ブロックはエクスポート時にテキストへ変換されるため、再インポートでは復元されない
