## 概要

デッキを URL 1本で他のユーザーと共有できる機能。
019（マーケットプレイス）の軽量版として、サーバー運用コストを最小化しながら共有を実現する。

## 技術メモ

- `lib/export.ts` の JSON エクスポートロジックを流用できる
- URL スキーム `codeflashcard://import?url=...` でディープリンク対応
- マーケットプレイス（019）とは異なり検索・評価機能は持たない
- サーバー側のストレージコスト試算が必要（JSON 1デッキあたり数KB〜数十KB）
