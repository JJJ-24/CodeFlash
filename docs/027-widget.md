## 技術メモ

- Expo では 2025年時点でウィジェットのサポートが限定的。`expo-widgets` の成熟度を確認してから着手する
- ウィジェットは Swift / SwiftUI で実装が必要になる可能性が高い（ネイティブモジュール）
- アプリ本体との DB 共有は App Group を使った SQLite ファイルの共有が現実的
- `lib/notifications.ts` の `updateBadgeCount()` と連動させると一貫性が保てる
