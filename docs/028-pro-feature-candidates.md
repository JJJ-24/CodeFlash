## 候補 1: デッキ・カードのカスタマイズ

ペイウォールに掲載予定の機能。デッキとカードの見た目を自由にカスタマイズできるようにする。

**着手状況:** 3フェーズに分割済み。
- フェーズ1: [028-1-deck-card-customization.md](028-1-deck-card-customization.md) — 色付きアイコン（**無料機能**として実装完了・コミット済み）
- フェーズ2: [028-2-card-display-theme.md](028-2-card-display-theme.md) — カード表示テーマ（**Pro 機能**として実装完了・コミット済み）
- フェーズ3: [028-3-font-customization.md](028-3-font-customization.md) — フォント変更（Pro 機能・未着手）

**配信方針メモ:** Pro 機能は「iCloud 同期・FSRS・詳細統計」を主力に置く方針。デッキアイコン/カラーは絵文字代替で実質無料相当のため、無料機能としてリリースし初期体験を豊かにする。Pro 訴求は 028-2（カードテーマ）と 028-3（フォント）に集中させる。

### サブ機能
- **デッキのアイコン**（複数候補から選択 or Ionicons 任意指定）
- **デッキのカラーテーマ**（プリセット + カスタムカラー）
- **カード表示のテーマカラー**（背景・枠線・コードブロック）
- **フォント変更**（プリセットの数種類から選択）

### 設計方針メモ：「色付きアイコン」として価値を出す

デッキ名の先頭にアイコンを置くだけなら、ユーザーが絵文字をデッキ名に入れることでほぼ同じ体験ができる（無料・即時）。
そのため、**専用アイコン機能の価値は「カラーテーマと組み合わせて『色付きアイコン』として表現できること」に置く**。

- アイコンは Ionicons 等の **単色ベクター**を採用
- デッキカラーをアイコンの fill 色に適用 → 絵文字では実現不可能な「**統一カラーリング**」を実現
- ウィジェット（027）と連動する際もタイル状にクリアに表示可能
- ベクター描画のため、デッキ詳細ヘッダーで**大サイズ装飾**としても利用できる

絵文字との差別化ポイントを明確にした上で機能を訴求する。

### 実装メモ
- `decks` テーブルに `iconName`・`colorHex` カラム追加（マイグレーション必要）
- `useSettingsStore` にグローバル `cardThemePreference`・`fontFamilyPreference` を追加
- 既存の `useTheme()` を拡張して `customColor` を返せるようにする
- フォントは expo-font で同梱（日本語対応必須）

### 想定難易度
中程度。マイグレーション + 設定 UI + 適用箇所の特定で数日規模。

## 候補 3: PDF / 印刷出力

学習記録・カード一覧を PDF として出力できるようにする。紙の単語帳として印刷する用途や、学習履歴の保存用途。

### サブ機能
- **デッキの全カードを PDF 化**（表面・裏面の2ペーン構成）
- **学習記録の月次レポート PDF**（学習日数・カード数・グレード分布）
- **印刷用 CSS** で iOS の印刷ダイアログから直接印刷

### 実装メモ
- `expo-print` ライブラリ使用
- HTML テンプレートをコード生成 → `printToFileAsync` で PDF 化
- `Sharing.shareAsync` で保存 / メール送信

### 想定難易度
低〜中。expo-print のみで完結し、ライブラリ追加リスクも低い。
