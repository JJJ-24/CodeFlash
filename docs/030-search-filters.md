## 概要

022（カード全文検索）に対して、デッキ・タグによる絞り込みフィルター機能を追加する。
028 候補4「詳細な検索機能」の一部として検討されていたが、無料機能として実装。

---

## 実装内容

### DB
- [x] `lib/database/cards.ts` の `searchCards(db, query, field, deckIds?, tagIds?)` を拡張
  - [x] `deckIds?: string[]` — `WHERE c.deckId IN (?,?,?)` を動的に生成（OR: 複数デッキのいずれか）
  - [x] `tagIds?: string[]` — `WHERE c.id IN (SELECT cardId FROM card_tags WHERE tagId IN (?,?,?))` を動的に生成（OR: 複数タグのいずれか）
  - [x] デッキ・タグ両方同時指定も可能（AND 結合）

### 検索画面（`app/search.tsx`）

  - [x] 1件以上選択中はプライマリカラーで強調（`albums` アイコンに切替）
- [x] タグ絞り込みボタン（`pricetag-outline` アイコン）をデッキボタン隣に追加
  - [x] 1件以上選択中はプライマリカラーで強調（`pricetag` アイコンに切替）
- [x] `DeckMultiSelectPickerModal` — デッキ複数選択用ボトムシートモーダル
  - [x] 「すべてのデッキ」行（何も選択されていない状態を表す）+ デッキ一覧（ソート順）
  - [x] タップでトグル選択（モーダルは閉じない）
  - [x] 選択中行は `primaryLight` 背景 + プライマリカラーテキスト + チェックマーク
  - [x] デッキアイコン（`DeckIcon`）を各行に表示
  - [x] 「完了」ボタンでモーダルを閉じる
- [x] `MultiSelectPickerModal` — タグ複数選択用ボトムシートモーダル（汎用）
  - [x] タグカラードットを各行に表示
  - [x] タップでトグル選択（モーダルは閉じない）
  - [x] 選択中行は `primaryLight` 背景 + プライマリカラーテキスト + チェックマーク
  - [x] 「完了」ボタンでモーダルを閉じる
- [x] アクティブフィルターチップ — 選択された各デッキ・タグを個別チップで表示
  - [x] デッキチップ（`albums-outline` + デッキ名 + `close`）× 選択数

  - [x] チップタップで該当フィルターを個別解除
- [x] `selectedDeckIds.join(',')` / `selectedTagIds.join(',')` を `useEffect` 依存配列に追加（切替時に即再検索）

## 設計メモ

- デッキ・タグともに複数選択 OR（いずれかに一致）で絞り込む
- AND 検索（すべてのタグを含む）は実装コストが高いわりにユースケースが限定的なため未実装
- `MultiSelectPickerModal`（タグ用）は `PickerItem = { id, name, color? }` の汎用型で設計。将来的に他のフィルター（習熟度など）にも流用可能
- 検索クエリが空でもフィルターのみで絞り込めるが、現状はクエリ空のとき結果を表示しない仕様（クエリ必須）
- ピッカーはタップでトグル選択し「完了」ボタンで閉じる方式（従来の単一選択＋即閉じ方式から変更）
