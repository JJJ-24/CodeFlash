## 概要

統計タブに「今日のサマリー」セクションを追加する。行には**今日の予定の消化率**（済み/復習の積み上げバー）を表示し、タップでシートを開くと**今日の評価内訳ドーナツ＋正答率・初学・平均時間**が見られる。

- **場所:** 学習履歴ヒートマップの下・「全体の学習率」の上。
- **行（常時表示）:** 済み/復習の積み上げバー（済み=緑 `FILTER_COLORS.learned`・復習=オレンジ `FILTER_COLORS.due`）＋実数ラベル「済み X」「復習 Y」＋消化率 %（`済み/(済み+復習)`）。体裁は「全体の学習率」行と同じ（surface カード・タップ可）。
- **タップでシート（`DonutSheet` 流用）:**
  - ドーナツ: 評価4色（もう一度/うろ覚え/わかった/バッチリ）＋**残り復習**をグレー（`#9E9E9E`・既存の「新規未習」スライスと同じ位置づけ）のスライスで表示
  - 中央の数字: 消化率 %（既存ドーナツと同じ「スライスから導出される割合」の文法）
  - グレード別グリッド: 各評価数＋%
  - 下段3項目（値・ラベル・単位）: **正答率 / 初学 / 平均時間**

## 用語・数値の定義（会話で確定した仕様）

| 項目 | 定義 | データ源 |
|---|---|---|
| 済み | 今日評価が保存されたユニークカード数 | `getTodayReviewedCount`（既存・`activeCardCond` あり） |
| 復習 | 残り due 枚数（未学習の新規カード含む） | `getTodayDueCount`（既存・`activeCardCond` あり） |
| 消化率 | `済み / (済み + 復習)` | 上2つから算出 |
| 評価内訳 | 今日の `grade_logs`（同日デデュープ済み＝カードごと最後の評価1件） | `getGradeLogTotals(db, todayStart)`（既存） |
| 正答率 | `(わかった + バッチリ) / 済み`（既存定義と同一） | 評価内訳から算出 |
| 初学 | 今日**初めて**学習したカード数（上部ブロック「新規」＝今日作成とは別物） | `MIN(review_logs.reviewedDate) = 今日`（新規クエリ） |
| 平均時間 | 今日の `grade_logs.responseTimeMs` の平均（秒・小数1桁） | 新規クエリ（または既存拡張） |

### 消化率が「厳密な今日予定の消化率」である根拠（検証済み）

- **今日作成のカード**はレビュー未登録＝due 扱い（`getTodayDueCount` は `r.cardId IS NULL` を含む）→ 作成で分母+1、学習で済みへ移動。
- **先取り学習**（「すべて」フィルターで future 予定のカードを評価）は `useStudySession.submitGrade` の `isDue || reviewedToday || hasCachedToday` ガードにより **`saveReview` 自体が呼ばれない** → 分子・分母とも不変。
- **「もう一度」でも同日中の再スケジュールは発生しない**（`lib/fsrs.ts` の `enable_short_term: false` により次回は最短で翌日）→ 評価した時点で復習→済みへ完全移動し、二重カウントなし。`済み + 復習 = 今日の対象カード実数` が常に成立。
- **同日の再評価**（セッション内再出題・「学習済み」フィルターの学び直し）は上書きのみ（`grade_logs` 同日デデュープ）→ 済み +0。

## 決定事項（設計の方針）

- **レイアウトは新規に作らず既存流用**: 行は「全体の学習率」行の体裁、シートは `DonutSheet`＋`GradeDistPieChart`。アプリ内の統計の文法（行＋バー→タップでドーナツシート）を守る。
- **`GradeDistPieChart` は今日版に対応できるよう軽く一般化する**（ヘッダー文言・グレースライスのラベル「新規」→「復習」・下段3項目の差し替えを props で指定可能に。既存の「全体の学習率」用の表示は変えない）。
- **中央の数字はスライスから導出**: `4評価合計 / (4評価合計 + 残り復習)`。既存ドーナツ（学習済み/全体）と同じく「中央の%＝色付きスライスの割合」になる。
- **行とシートの母数の僅差は許容**: 行の済み/復習は `activeCardCond` 適用（既存関数）、シートの評価内訳は `grade_logs` ベースでアーカイブ除外なし（032 の「過去実績は消さない」方針どおり）。「今日学習→同日中にアーカイブ」という稀な操作でのみ両者がずれるが、対処しない（チケット追記で注記のみ）。
- **空状態**: 済み 0・復習 0 の日は % を「—」表示、バーは `theme.colors.progressBg` のみ。シートは開けるが評価内訳なしの空表示（`GradeDistPieChart` は total 0 で null を返す既存挙動を踏襲し、EmptyState 的な文言を出す）。
- **情報モーダル**: セクションタイトル横の ⓘ で説明（既存 `sectionInfoModal` パターン）。「済み・復習・初学・消化率」の定義（特に「新規＝今日作成」との違い、先取り学習は含まれないこと）を明記する。
- **無料機能**（Pro ゲートなし）。今日スコープは完了画面（無料・セッション単位）と同じ線引きで、Pro の価値は過去に遡れる分析（月別・ランキング・カード別）で維持される。

### 掲載を見送った項目（再検討時の参考）

- **学習回数**: `grade_logs` は同日デデュープのため当日件数＝ユニークカード数＝「済み」とほぼ同値（差はアーカイブ経由のみ）。独立項目の価値なし。延べ回数を出すにはデデュープ廃止が必要で、FSRS の「同日=やり直し」哲学・苦手カード集計・正答率定義に波及するため見送り。
- **学習時間**: 実測データなし。`responseTimeMs` 合計は「表面表示→評価」の近似で放置に弱く、≒回数×平均時間で冗長。正確にやるなら学習画面滞在時間の永続化が先（別チケット級。036 の v1 スコープ外にも記載あり）。
- **残り復習の独立欄**: 上部ブロック「復習」（`getTodayDueCount`）と完全重複。バーとグレースライスで表現済み。
- **ストリーク・学習日数**: ヘッダー/学習の記録に既出・「今日」には無意味。

## 影響範囲

- `lib/database/reviews.ts` … 新規 `getTodayStudySummary(db)`（または小関数2つ）: 今日の平均回答時間（`AVG(responseTimeMs)`・今日の `grade_logs`）＋初学カード数（`review_logs` を `cardId` で GROUP BY し `MIN(reviewedDate) = localDateStr(今日)` を COUNT）。評価内訳は既存 `getGradeLogTotals(db, todayLocalRange().start)` を流用。
- `app/(tabs)/stats.tsx` …
  - セクション追加（ヒートマップの下・全体の学習率の上）: タイトル＋ⓘ＋タップ可能な行（積み上げバー＋済み/復習ラベル＋%）
  - シート表示: 既存 `DonutSheet` に今日版 `GradeDistPieChart` を渡す
  - データ読込: 既存の load（focus / `dataRevision` 連動）に新規クエリを追加。済み/復習は既存 state（`todayReviewed`/`todayDue`）を流用
  - キーボード: J/K フォーカスサイクルに行を組込み・Return で開閉（既存「シート表示中は Return で閉じる」慣習）・シート表示中は背景キー抑止（既存 `active` ゲート）
- `app/(tabs)/stats.tsx` 内 `GradeDistPieChart` … ヘッダー文言・グレースライスラベル・下段3項目を差し替え可能にする一般化（既存呼び出しの表示は不変）
- `locales/ja.json` / `en.json` … セクションタイトル「今日のサマリー」・「済み」「復習」「初学」「消化率」ラベル・情報モーダル文言（必ずセットで）

**新規ライブラリ依存なし・DB スキーマ変更なし・設定追加なし**（`lib/settings-keys.ts` 対応不要）。

### 再利用する既存部品

- 行の体裁・タップ→シート: 「全体の学習率」行＋`DonutSheet`
- ドーナツ＋グリッド＋下段3項目: `GradeDistPieChart`（`lib/donut.ts` の定数・パス計算）
- バー色: `FILTER_COLORS.learned` / `FILTER_COLORS.due`（`lib/theme`）・グレースライス `#9E9E9E`（既存の未習スライスと同色）
- 日付範囲: `todayLocalRange()` / `localDateStr()`（`lib/database/utils.ts`）
- 情報モーダル: `sectionInfoModal`＋`InfoContent`（フェード中の内容保持 ref `lastSectionInfoRef` の既存慣習に従う）
