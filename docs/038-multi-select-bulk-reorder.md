## 概要

選択モード（カード一覧・タグ管理）で複数選択した項目を、**まとめて並べ替え**できるようにする。離れた位置の選択にも対応し、移動後は選択順を保ったまとまりとして挿入される。

2段階で実装する：

- **① キーボード版（低リスク・先行）**: 複数選択後の `U`/`D` で、選択カード群（**表示順のまま**）を「U=**選択中の最上部カードの1つ上** / D=**最下部カードの1つ下**」へ集約配置する。毎回の押下が移動方向への変化になり、離れた選択は移動方向へ集約、隣接ブロックは1つずつ上下移動（式の自然な帰結）。端はクランプ。**選択順には依存しない**（2026-07-18 変更：旧「最初に選択した位置へ選択順に集約」は選択順が画面に見えず結果を予測できないため不採用）。ジェスチャー不要の純粋な配列操作＋既存 sortOrder 保存。
- **② タッチ版（グループ行方式）**: 複数選択後に選択カードのどれかを**長押しすると、選択カードが長押し位置の1行「束カード」に集約**され（重なった見た目＋「×N」バッジ）、既存の単一行ドラッグでまとめて移動、ドロップ位置に選択順どおり展開挿入される。

**有効条件**（既存の手動並べ替えと同じ）: カード一覧＝「すべて」フィルター＋手動ソート＋ロック解除時のみ。タグ管理＝手動ソート＋ロック解除時のみ。

## 設計方針（会話で確定・2026-07-12）

- **「ドラッグするのは常に1行」を守る**: 並べ替えは `react-native-draggable-flatlist`（patch 適用済み）に依存しており、**複数行ドラッグはライブラリ非対応**。行位置は内部の reanimated ワークレット管理のため、「複数行が吸い寄せられて束になる」本格アニメーション版はフォーク級の改造が必要で**非推奨・見送り**（ドロップちらつき許容の経緯がある壊れやすい領域。`docs/`メモ: project_reorder-drop-flicker）。
- **②は「束化＝データ変換」で実現**: 長押し時に選択カードをデータ配列から一時的に抜き、長押し位置の行を束カード（1行）に差し替える。束はただの1行なのでライブラリでそのままドラッグ可能。ドロップで展開＋sortOrder 一括保存。集約の瞬間はアニメーションなしの切替（LayoutAnimation 不使用の方針と整合）。
- **①の集約は即・実移動**: U/D の押下ごとに配置（集約含む）が並べ替えとして確定（DB 反映）する。選択モード解除で元に戻す機能は持たない（一時状態の永続化が複雑になるため）。
- **②のキャンセル復元**: 束化はドラッグ中の一時状態。ドロップで確定、**ドラッグせず選択モード解除した場合は束化前の並びに戻す**（束化時に元配列のスナップショットを保持）。
- 束カードの見た目: 先頭カードのプレビュー＋重なり表現＋「×N」バッジ（詳細は実装時に調整）。

## リスク・副作用（実装時に必ず確認）

- **ドロップ時の視覚ジャンプが二重になる**: ライブラリ既知のドロップちらつき＋束の展開が重なる。大リストでは仮想化の限界（project_cardlist-jk-wrap-scroll-limit と同種）でパラパラしうる → 許容ラインを実機で判断
- **ドラッグ中の iCloud 同期**: `dataRevision` 再読込がドラッグ/束化中に走ると配列が入れ替わる → 束化中は再読込を遅延 or 束を破棄して復元
- **SwipeToDeleteRow との競合**: 手動ソート時のスワイプ可否（ロック仕様）と束カード上のジェスチャーの整理
- **J/K フォーカス**: `useListNavigation` は ID ベース追跡なので並べ替えには追従するが、「束カード」という合成行の ID 設計が必要（束化中は束 ID・展開で元 ID に戻す）
- **選択順の定義**: ①は選択順に依存しない設計へ変更済み（表示順＋方向集約・2026-07-18）＝ Set のままでよい。②タッチ版の束の展開順も**表示順**とする（同じ理由）

## 影響範囲

- `app/deck/[id]/index.tsx` … 選択モードのキー処理（U/D）・束化/展開ロジック・DraggableFlatList の data 差し替え
- `app/tags/index.tsx` … 同上（タグ版）
- `hooks/useListNavigation.ts` … 束カード ID の扱い（必要なら）
- `lib/database/cards.ts` / `decks.ts`（tags.ts） … sortOrder 一括更新（既存の並べ替え保存を流用。新規クエリは原則不要）
- `locales/ja.json` / `en.json` … 束バッジ・ⓘ/ショートカット一覧の説明（セットで）
- ShortcutsModal の選択モード欄 … U/D = まとめ移動 の記載

**新規ライブラリ依存なし・DB スキーマ変更なし**（sortOrder の更新のみ）。
