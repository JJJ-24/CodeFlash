# 055 デッキ/タグの新規・編集画面を J/K のフォーカスで操作する

**フェーズ:** Phase 1（共通の仕組みの切り出し＋4画面）
**ステータス:** Phase 1 完了（実機確認済み 2026-09-25）
**要ネイティブ再ビルド:** 不要（JS のみ）
**依存:** 034（ネイティブ UIKeyCommand）・053（設定の詳細画面のフォーカス）
**被依存:** なし

---

## 概要

デッキ/タグの新規・編集の4画面（`app/deck/new.tsx`・`app/deck/[id]/edit.tsx`・`app/tags/new.tsx`・`app/tags/[tagId]/edit.tsx`）は、
これまで**文字キーで各項目へ直接**届く仕様だった（N＝名前・M＝説明・C＝色・I＝アイコン・R・⇧R・H・Q・E）。
設定の詳細画面（053）と同じ **J/K で項目を選び、Return/Space/`,`/`.` で操作する**形を足して、他の画面とそろえる。

**文字キーは残す**（2026-09-25 合意）＝1押しで直接届くほうが速く、慣れた人の手を奪わない。J/K は「覚えていなくても辿り着ける道」として足す。
J/K の操作と文字キーは同じ処理を呼ぶだけなので、両方あってもぶつからない。

---

## 操作

J/K で上から順に項目へフォーカス（青枠・画面外なら自動スクロール・ヌルサイクル）。

| 項目 | 操作 |
|---|---|
| デッキ名・説明・タグ名 | Return＝入力を始める（カーソルが入る）。Esc で入力をやめるとフォーカス（青枠）に戻る |
| 色 | `,`/`.`＝色を送る（C/⇧C と同じ） |
| アイコン（デッキ） | Return＝選択画面を開く |
| 読み上げ（デッキ・トグル） | Space |
| 読み上げの設定・HTML/CSS 土台・SQL 初期化（デッキ） | Return＝開く（非 Pro は従来どおり Pro の案内） |
| アーカイブ（デッキ編集・トグル） | Space |

- **Return＝開く・入る／Space＝スイッチ**（053 と同じ）。
- **色の左右は `,`/`.` だけ**（H/L は使わない）：デッキ画面では H が「HTML/CSS 土台を開く」に使われていて、文字キーを残すため。
  4画面でそろえてタグ画面も `,`/`.` だけにする。
- **矢印は使わない**：この4画面は元から「iPad のフォーカスエンジンとの衝突を避けるため矢印・Tab を使わない」方針（入力欄もある）。
- **Esc の順**：入力中ならカーソルを外す → インライン説明 → フォーカスを外す → 閉じる（変更があれば破棄の確認）。
- **S＝保存・X＝閉じる・Delete＝削除・U/D などのスクロールは従来どおり**。
- 入力欄にカーソルがあるあいだは文字キー（J/K 含む）は入力欄に入る（034 の住み分け・従来どおり）。
- タグの「プレビュー」欄は表示だけなのでフォーカスを止めない。
- **キー以外の経路でも青枠を移す**（2026-09-25 実機確認で追加）：①入力欄にカーソルが入ったら（Return で説明欄へ移ったとき・タップ）その欄
  ②**項目の中をタップしたら**その項目（色の見本・スイッチ・行など中の部品も含む＝項目を包む View のタッチで判定）。
  最後に触った場所からキー操作を続けられる（一覧画面で行をタップするとフォーカスが残るのと同じ考え方）。
  ⚠️ スクロールのために指を置いただけでは移さない（指の移動が 10pt 未満のタップだけ）。
  ⚠️ **キーボードショートカットが ON のときだけ**（OFF の人には青枠は意味が無い。OFF にしたら残っている青枠も消す）。
  **設定の詳細画面（053）にも同じ動きを入れた**（部品が共通・画面で動きが違うと分かりにくい）。
- 矢印キーでデッキ名の欄にカーソルが入るのは iPadOS のフォーカスエンジン（矢印/Tab で操作できる部品を選ぶ OS の機能）。
  この画面は入力欄があるので矢印を登録しない（登録すると入力中に矢印でカーソルを動かせなくなる＝CLAUDE.md「iPad の落とし穴」）＝**そのままにする**。

## 実装

- 053 の `SettingsDetail` が持っていたフォーカス管理（登録・縦位置順の並べ替え・ヌルサイクル・自動スクロール）を
  **`useFocusRegistry`（`components/settings/settingsFocus.tsx`）に切り出し**、`SettingsDetail` と4画面で共用する。
  項目の部品（`SettingsFocusRow` など）はそのまま使う。
