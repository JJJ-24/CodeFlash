# 056 カード編集・新規作成の J/K をブロックの後ろ（ブロック追加・タグ・アーカイブ）まで広げる

**フェーズ:** Phase 1
**ステータス:** Phase 1 完了（実機確認済み 2026-09-26）
**要ネイティブ再ビルド:** 不要（JS のみ）
**依存:** 034（ネイティブ UIKeyCommand）・053/055（J/K のフォーカス・Return＝開く／Space＝スイッチ）
**被依存:** なし

---

## 概要

カード編集・新規作成（`BlockEditor`）の J/K はこれまで**ブロックだけ**を巡回していた。
055 でデッキ/タグの新規・編集を J/K で操作できるようにしたのに合わせ、ブロックの後ろの項目にも届くようにする。
特に**タグはキーで付け外しする手段が無かった**（`T` はスクロールだけ）。

文字キー（`A`＝ブロック追加メニュー・`E`/`⇧E`＝アーカイブ）はそのまま残す（055 と同じ判断）。

## 操作（編集モードのみ）

巡回：**ブロック0…n → ＋ブロック追加 → タグ → アーカイブ → フォーカスなし**（ヌルサイクル・K は逆順）。

| 項目 | 操作 |
|---|---|
| ＋ブロック追加 | Return＝メニューを開く（`A` と同じ）。メニューを閉じるとフォーカスはここへ戻る |
| タグ | Return＝**タグ選択シート**を開く（J/K で移動・Space で付け外し・Return/Esc で閉じる）。`T`＝タグ欄へフォーカス |
| アーカイブ（編集時のみ） | Space＝切り替え（`E`/`⇧E` は従来どおり） |

- **並べ替えモードはブロックだけ**（2026-09-26 合意）＝並べ替えの J/K は「U/D で動かすブロックを選ぶ」ため。プレビューは J/K 自体が無効のまま。
- **タグ欄は1項目**で、チップ1つずつには止めない（2026-09-26 合意の案 A）。
  不採用：B＝フォーカス中に `,`/`.` でチップ移動（この画面の `,`/`.`・H/L は表/裏/メモの切替なので、フォーカス位置で意味が変わる）／
  C＝チップごとに止める（タグの数だけ巡回が延び、アーカイブまで遠くなる）。
  シートは検索のタグ絞り込みと同じ部品（`components/MultiSelectPickerModal.tsx` に切り出し。カード編集では「すべて」行を出さない）。
- タグが1つも無いときはタグ欄に止めない（選べるものが無い）。デッキ名の行は表示だけなので止めない。
- **末尾の項目にフォーカス中の Delete は何もしない**：従来の「ブロックにフォーカス＝ブロック削除／なし＝カード削除」を末尾へ延長すると、
  タグを選んでいるつもりの Delete がカード削除の確認に繋がるため。
- `E`（フォーカスなし時＝アーカイブ）は、末尾の項目にフォーカス中も「ブロックにフォーカスが無い」扱いでアーカイブを切り替える（カード単位の操作）。
- **Esc の順を 055 にそろえた**：追加メニュー → 入力中ならカーソルを外す → **フォーカス（青枠）を外す** → 閉じる。
  以前はブロックの青枠が残ったままでも Esc で閉じていた。
- タップでも青枠を移す（055 と同じ・ショートカット ON のときだけ・指の移動 10pt 未満だけ）＝末尾の3項目のみ。

## 実装

- ブロックは従来の `focusedBlockIndex`、末尾は新しい `footerFocus`（`'add' | 'tags' | 'archive'`）で持ち、同時に立てない。
  055 の `useFocusRegistry` へブロックごと移す案は不採用（ブロックの位置取り・編集開始のスクロールが既にあり、作り直すリスクに見合わない）。
- 画面外なら見える位置までスクロール（055 と同じ上下 8pt）。位置は各項目の `onLayout`。
- タグ選択シート表示中はエディタのキー（main＋Esc）を解除する（シートが自前で受け持つ）。
