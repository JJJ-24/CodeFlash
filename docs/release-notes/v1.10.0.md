## 日本語

```
HTML / CSS のプレビュー実行（Pro）とアーカイブ一覧画面を中心としたアップデートです。

【新機能・改善】
・HTML / CSS のプレビュー実行に対応（Pro）：HTML・CSS のコードブロックを実行すると、結果がその場で「見た目」として表示されます。JavaScript / TypeScript のブロックも、デッキやブロックに用意した HTML/CSS の「土台」を操作して結果を確かめられます。実行前は土台だけを表示するので、「このコードを足すとどう変わる？」という出題ができます
・全画面のインタラクティブプレビューを追加（Pro）：プレビュー右上の全画面ボタンで表示が切り替わり、ボタンのクリックや入力など実際に操作しながら動きを確認できます。下部には console の出力がリアルタイムで流れます
・HTML の画像ライブラリを追加（Pro）：デッキに写真を登録しておくと、HTML から `<img src="img://名前">` の形で呼び出せます。画像そのものは端末内に保存されるため、カードの内容が重くなりません
・「ソース」タブを追加（Pro）：実行前は土台の HTML、実行後は実行結果の DOM を読みやすく整形して表示します。土台や初期化 SQL にはコピーボタンも付きました
・アーカイブ一覧画面を追加：設定タブ →「アーカイブ」から、アーカイブしたデッキ・カードを一覧で確認できます。選択して一括で解除・削除もできます
・アーカイブ中のデッキでも学習を始められるように：「アーカイブを解除して学習」か「閲覧のみ（記録なし）」を選べます。閲覧モードでは学習記録が一切残らないので、内容の確認だけしたいときに使えます
・複数のカード／タグをまとめて並べ替えられるように：選択モードで選んだ行を U / D キー、または長押しドラッグでまとめて移動できます
・学習中にタグを付け外しできるように：裏面にタグ行を表示し、タップまたは T キーでシートを開いてその場で付け外し・新規作成ができます（編集画面への往復が不要に）
・コード実行の待ち時間を改善：setTimeout で先の処理を予約したコードは、その時刻に合わせて実行の上限を自動で延長します（最大30秒）。また実行中の console 出力が逐次表示されるようになり、setInterval のような「時間をかけて動くコード」の途中経過が見えるようになりました
・コード実行で alert が使えるように
・テキストブロックにマークダウンの書き方ヘルプを追加：ブロックヘッダーのヘルプアイコンから、使える記法の早見表を書きながら確認できます
・マークダウンのテーブルを見やすく改善（見出し行の強調・列の縦線）。テキストブロック内のコードフェンスもシンタックスハイライトされるようになりました
・TSV エクスポート／インポートでコードブロックを保持できるように：マークダウンのコードフェンス付きで書き出し、読み込み時に言語付きのコードブロックへ戻します。TSV で失われる内容（SQL 初期化・HTML 土台・画像）があるデッキでは、書き出す前に内訳を確認できます

【不具合の修正】
・並べ替えロックを切り替えると一覧が先頭までスクロールしてしまう不具合を修正
・同じ位置に戻すドラッグをした後、以降の並べ替えで端まで運んでも自動スクロールしなくなる不具合を修正
・iPad で選択モードを切り替えると一覧が先頭へ飛ぶことがある不具合を修正
・アーカイブ済みデッキのカード一覧で、初期フィルターの設定によっては何も表示されないことがある問題を修正（常に「すべて」で開くようにしました）

その他、学習タイマーの表示の微調整、実行結果のコピー内容、選択モード中のヘッダー表示、コードブロックの言語選択の並びなど、細かな改善を含みます。
```

## English

```
This update centers on HTML / CSS preview execution (Pro) and a new Archive screen.

[ New & Improved ]
• Added HTML / CSS preview execution (Pro): running an HTML or CSS block now renders the actual result right in the card. JavaScript / TypeScript blocks can manipulate an HTML/CSS "stage" you define per deck or per block. Before running, only the stage is shown — perfect for "what changes when you add this code?" questions
• Added a full-screen interactive preview (Pro): tap the full-screen button on the preview to actually interact with your page — click buttons, type into inputs — while console output streams live at the bottom
• Added an HTML image library (Pro): register photos on a deck and reference them from HTML as `<img src="img://name">`. The image itself stays on the device, so your cards don't get heavy
• Added a "Source" tab (Pro): shows the stage HTML before running and a nicely formatted DOM after running. Copy buttons were added to stages and SQL setup code as well
• Added an Archive screen: Settings → "Archive" lists your archived decks and cards, where you can select multiple items to unarchive or delete them in bulk
• You can now study from an archived deck: choose "Unarchive and study" or "View only (no records)". View-only mode writes no study history at all — handy when you just want to review the content
• You can now reorder multiple cards / tags at once: select rows, then move them together with the U / D keys or a long-press drag
• You can now add and remove tags while studying: a tag row appears on the card back; tap it (or press T) to open a sheet and edit tags — or create a new one — without leaving the study screen
• Improved code execution timing: code that schedules work with setTimeout now automatically extends the execution limit to match (up to 30 seconds). Console output is also streamed while running, so you can watch the progress of time-based code such as setInterval
• alert now works in code execution
• Added a Markdown cheat sheet to text blocks: tap the help icon in the block header to check the supported syntax while you write
• Improved Markdown tables (bold header row, column dividers), and code fences inside text blocks are now syntax highlighted
• TSV export / import now preserves code blocks: blocks are written as Markdown code fences and restored with their language on import. For decks containing content TSV can't carry (SQL setup, HTML stages, images), you'll see a breakdown before exporting

[ Bug fixes ]
• Fixed an issue where toggling the reorder lock scrolled the list back to the top
• Fixed an issue where auto-scrolling stopped working during later drags after you dropped an item back in its original position
• Fixed an issue on iPad where switching selection mode could jump the list to the top
• Fixed an issue where a card list for an archived deck could appear empty depending on your initial filter setting (it now always opens with "All")

Plus minor improvements to the study timer display, the copied text of execution results, the selection-mode header, and the order of the code block language list.
```

## v1.10.0 の変更点
主な変更は、HTML / CSS コードブロックのプレビュー実行とデッキ／ブロック単位の HTML・CSS 土台（Pro）、
全画面インタラクティブプレビュー（Pro・操作可能な WebView ＋ ライブ console）、
HTML 画像ライブラリ（Pro・`img://名前` を実行時に data URI へ解決）、
アーカイブ一覧画面（デッキ／カードの2タブ・一括解除／一括削除）、
アーカイブ中デッキからの学習（解除して学習／閲覧のみの2択・閲覧モードは学習記録を残さない）、
選択したカード／タグのまとめ並べ替え（U/D キー・長押しドラッグ）、
学習画面からのタグ付け外し、コード実行の締切延長・実行中ログの逐次表示・alert 対応、
マークダウン（テーブル表示・書き方ヘルプ・コードフェンスのハイライト）、
TSV でのコードブロック往復と書き出し前の欠落確認、
および並べ替えロック切替時のスクロール位置・iPad の選択モード切替・学習タイマー表示などの不具合修正です。
新たな外部通信・新規 IAP はありません。

### 主なテスト手順
1. **HTML / CSS のプレビュー実行（Pro）**
   - カード編集でコードブロックを追加し、言語を html にして `<h1>hello</h1>` などを入力 → 実行
   - 結果がプレビューとして表示されること、［プレビュー / ソース］を切り替えられることを確認
   - デッキ編集の「HTML/CSS 共通土台」に土台を入れると、javascript ブロックからその土台を操作できることを確認
2. **全画面インタラクティブプレビュー（Pro）**
   - プレビュー右上の全画面ボタンをタップ → 全画面で表示され、ボタンのクリック等が実際に動作すること
   - ヘッダーの実行ボタンで実行、リセットボタンで実行前（土台のみ）に戻ること、閉じるボタンで閉じることを確認
3. **HTML 画像ライブラリ（Pro）**
   - デッキ編集 → HTML/CSS 共通土台 → 画像ライブラリから写真を追加し、名前を付ける
   - HTML ブロックに `<img src="img://名前">` と書いて実行 → 画像が表示されることを確認
4. **アーカイブ一覧**
   - 一覧の左スワイプなどでデッキ／カードをアーカイブ → 設定タブ →「アーカイブ」を開く
   - ［デッキ］［カード］タブの切替、選択モードでの一括解除・一括削除を確認
   - アーカイブ中のデッキのカード一覧から学習を開始 → 2択ダイアログが出ること、「閲覧のみ」では評価ボタンが出ず記録が残らないことを確認
5. **まとめ並べ替え**
   - カード一覧（手動ソート・フィルター「すべて」）で選択モードにし、複数選択 → U / D キーまたは選択行の長押しドラッグでまとめて移動できることを確認
6. **学習中のタグ付け外し**
   - 学習画面で裏面を表示 → タグ行をタップ（または T キー）→ シートで付け外し・新規作成ができることを確認
