## 日本語

```
カードの読み上げとスペイン語表示に対応したアップデートです。

【新機能・改善】
・カードの読み上げに対応：学習画面のスピーカーボタン（S キー）で、表示中の面を読み上げます。日本語と英語のように文字の種類が違う文は自動で読み分け、声と速さも選べます
・デッキごとに読み上げの言語を指定できるように（Pro）：アプリ全体の設定は英語のまま、このデッキだけスペイン語、といった使い分けができます。表面と裏面で別の言語にも分けられます
・自動読み上げ（Pro）：カードを表示したとき・裏返したときに自動で読み上げます。オフ・表面・裏面・両面から選べ、デッキごとに変えることもできます
・デッキごとに読み上げをオフにできるように：プログラミングのデッキではボタンを出さない、といった使い分けができます
・スペイン語表示に対応：設定 → 表示 → 表示言語から選べます
・検索に「学習した日」フィルターを追加：その日に学習したカードだけを一覧できます。統計の「済み」の棒グラフをタップしても開けます
・検索で選んだ面が、結果一覧に出す面も兼ねるようになりました：裏面やメモで検索したとき、何にヒットしたのかが一覧から読めます
・1日の目標の表示を拡充：達成の知らせ方を3種類から選べるようになり、残り枚数のバッジ、統計「これまでの歩み」での達成状況、過去7日グラフの目標ラインを追加しました
・学習タイマーが同じ日のうちは残るように：アプリを閉じても続きから再開でき、日をまたぐとリセットされます
・バックアップからの復元を分かりやすく：デッキごとに「戻せる差分の件数」を表示し、並び順だけを戻すこともできます。「すべて置き換え」の確認では、戻るものと失うものの両方を出します
・評価別ランキングに「学習履歴が残るカードのみ」の絞り込みを追加（Pro）
・学習設定を折りたためるようにしました：閉じているときは設定内容を1行で表示します

【不具合の修正】
・iPad でキーを長押ししたときのアクセント候補が、白い背景に白い文字で読めなくなる不具合を修正
・文字サイズを大きくすると、説明や確認のダイアログが画面からはみ出し、閉じるボタンを押せなくなる不具合を修正
・確認ダイアログや説明を閉じた直後、一覧のスワイプが効かない不具合を修正
・通知スケジュールのラベル入力欄がキーボードに隠れる不具合を修正
・表示言語を変えるたびに iCloud 同期の通知が再表示される不具合を修正
・iPad で画面幅を狭めると、ボタンや数字がタイトルを押し出してレイアウトが崩れる不具合を修正
・デッキの HTML/CSS 土台を追加して何も入力せずに閉じると、空の土台が残る不具合を修正
・カード編集の「コピー」で作った複製を、閉じるボタンで閉じても取り消せなかった不具合を修正（保存するか複製を削除するかを選べます）
・カード編集画面のタイトルが「カ…」のように1文字に省略されることがある不具合を修正
・テキストブロックで、「」などの記号に隣接したマーカー・太字・訂正線・下線が効かない不具合を修正（例：あいうえお==「かきくけこ」== が黄色にならない）

その他、設定・統計・検索・一覧の説明文とレイアウトの見直し、選択モード中の操作説明の追加、学習タイマーの終了時の動作に「なし」を追加するなど、細かな改善や修正を含みます。
```

## English

```
This update adds read-aloud for cards and Spanish as a display language.

[ New & Improved ]
• Added read-aloud for cards: tap the speaker button on the study screen (or press S) to hear the side you are looking at. In sentences that mix writing systems, each part is read with the voice that fits it, and you can pick the voice and the speed
• You can now set a speech language per deck (Pro): keep the app on English but read this one deck in Spanish. You can also use a different language for the front and the back
• Auto read-aloud (Pro): cards are read automatically when shown or flipped. Choose off, front, back or both sides, and override it per deck
• Read-aloud can be turned off per deck: hide the button in a programming deck, for example
• Added Spanish as a display language: Settings → Display → Display Language
• Added a "Studied on" filter to search: list only the cards you studied on a given day. Tapping a bar in the "Done" chart on the Stats tab opens the same list
• The side you pick in search is now also the side shown in the results: when you search the back or the memo, you can see what actually matched
• Expanded the daily goal display: choose from three ways to be told when you reach it, plus a remaining-count badge, goal status in "Journey" on the Stats tab, and a goal line on the 7 day chart
• The study timer now carries over through the day: close the app and pick up where you left off, and it resets when the date changes
• Clearer restore from backup: each deck now shows how many items you can actually get back, and you can restore just the card order. The "Replace All" confirmation shows both what comes back and what you lose
• Added an "Only cards that update history" filter to Grade Ranking (Pro)
• Study Settings sections can now be collapsed, showing a one-line summary when closed

[ Bug fixes ]
• Fixed an issue on iPad where the accented letters shown by holding a key were white text on a white background
• Fixed an issue where explanation and confirmation dialogs could run past the screen at large text sizes, putting the close button out of reach
• Fixed an issue where list swipes did not work right after closing a confirmation dialog or an explanation
• Fixed an issue where the label field of a notification schedule was hidden behind the keyboard
• Fixed an issue where the iCloud sync notice reappeared every time you changed the display language
• Fixed a layout issue on iPad where narrowing the window left titles so little room that they wrapped one character per line
• Fixed an issue where adding an HTML/CSS stage to a deck and closing without typing anything left an empty stage behind
• Fixed an issue where a card created with "Copy" in the card editor stayed behind even when you closed the editor without saving (you can now choose to keep it or delete the copy)
• Fixed an issue where highlight, bold, strikethrough, and underline in text blocks did not apply when the marks were next to punctuation such as Japanese brackets or quotation marks

Plus refreshed wording and layout across Settings, Stats, search, and the lists, on-screen guidance for selection mode, and a "Nothing" option for what happens when the study timer ends.
```

## Español

Esta actualización incorpora la lectura en voz alta de las tarjetas y el español como idioma de la app.

[ Novedades y mejoras ]
• Lectura en voz alta de las tarjetas: toca el botón del altavoz en la pantalla de estudio (o pulsa S) para escuchar la cara que estás viendo. En las frases que mezclan sistemas de escritura, cada parte se lee con la voz que le corresponde, y puedes elegir la voz y la velocidad

• Español disponible como idioma de la app: Ajustes → Pantalla → Idioma de la app
• Nuevo filtro "Día de estudio" en la búsqueda: muestra solo las tarjetas que estudiaste ese día. También se abre tocando una barra del gráfico "Hechas" en Estadísticas

• Las secciones de Ajustes de estudio ahora se pueden plegar y muestran un resumen en una línea

• El campo de nombre de una programación de notificación quedaba oculto tras el teclado
• El aviso de sincronización con iCloud reaparecía cada vez que se cambiaba el idioma de la app
• En iPad, al estrechar la ventana los títulos se quedaban sin espacio y se partían carácter a carácter

• Al cerrar sin guardar una tarjeta creada con "Copiar" en el editor, la copia se quedaba de todos modos (ahora puedes elegir guardarla o eliminarla)

Además, se han revisado los textos y la disposición de Ajustes, Estadísticas, la búsqueda y las listas, se han añadido indicaciones en pantalla para el modo de selección y una opción "Nada" para lo que ocurre al terminar el temporizador.

## 主なテスト手順
1. カードの読み上げ
   - 学習画面でカードを表示 → 左下のスピーカーボタン（またはハードウェアキーボードの S キー）で読み上げが始まることを確認
   - 日本語と英語が混ざったカードで、文字の種類ごとに声が切り替わることを確認
   - 設定 → 学習 → 読み上げ で、言語・声・速さを変更できることを確認
2. デッキごとの読み上げ言語（Pro）
   - デッキ編集 → 読み上げの言語 を開き、文字体系ごとに言語を選択
   - そのデッキのカードが選んだ言語で読まれることを確認
   - 「裏面を別の言語で読む」をオンにすると、表面と裏面で別の言語になることを確認
   - Pro 未購入の状態ではデッキ編集の行に鍵アイコンが出て、タップすると Pro の案内が開くことを確認
3. スペイン語表示
   - 設定 → 表示 → 表示言語 で Español を選択 → 画面全体がスペイン語表示になることを確認
4. 検索の「学習した日」フィルター
   - 学習を行った後、検索画面のカレンダーアイコンをタップ → その日に学習したカードが一覧されることを確認
   - 統計タブの「済み」の棒グラフをタップしても同じ一覧が開くことを確認
5. バックアップからの復元
   - 設定 → iCloud 同期 → デッキ別に戻す を開き、デッキごとに戻せる差分の件数が表示されることを確認
