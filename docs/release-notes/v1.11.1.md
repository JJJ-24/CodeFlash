```
自動読み上げと、学習履歴（草グラフ）の目標達成表示を追加したアップデートです。

【新機能・改善】

その他、細かな文言と表示の調整を含みます。
```

## English

```
This update adds auto read-aloud and a goal view for your activity history.

[ New & Improved ]
• Auto read-aloud (Pro): cards are read automatically when shown or flipped. Choose off, front, back or both sides, and override it per deck
• Read-aloud can be turned off per deck: hide the button in a programming deck, for example
• Added a "Goal" view to the activity heatmap (Activity on the Stats tab): once you set a daily goal, the past year can be shown either by study volume or by whether you reached the goal, so the days you made it stand out
• Tap a badge in Stats → Learning Record to see when you earned it, or how much is left until you do
• window.open now works in the HTML preview (Pro): in the full screen preview, an http(s) URL opened from a link or a button opens in Safari, and window.close() closes the preview
• Reworked the explanations behind the i buttons: headings and items now follow one format, and an explanation opens only when you tap the i icon

[ Bug fixes ]
• Fixed an issue where highlight, bold, strikethrough, and underline in text blocks did not apply when the marks were next to punctuation such as Japanese brackets or quotation marks
• Fixed an issue where tapping the name of a settings row opened its explanation instead of the setting
• Fixed an issue where the goal reminder still fired, and the app icon badge stayed out of date, after study done on another device was synced in from iCloud

Also includes minor wording and display adjustments.
```

```
## 主なテスト手順
1. 自動読み上げ（Pro）
   - 設定 → 学習 → カード読み上げ → 自動読み上げ で「両面」を選択
   - 学習画面でカードを表示したとき・裏返したときに、自動で読み上げが始まることを確認
   - デッキ編集 → 読み上げの設定 → 自動読み上げ で、そのデッキだけ別の面に変えられることを確認
     （先頭の「アプリ設定」を選ぶと上書きが解除される）
   - Pro 未購入の状態では、設定の行に鍵アイコンが出て値が常に「オフ」と表示され、
     タップすると Pro の案内が開くことを確認
2. デッキごとの読み上げオフ（無料）
   - デッキ編集 →「読み上げ」トグルをオフ → そのデッキの学習画面にスピーカーボタンが出ないことを確認
   - 下の「読み上げの設定」の行が淡くなり、動作しない理由が表示されることを確認
3. 学習履歴（草グラフ）の目標達成表示
   - 設定 → 学習 → 1日の目標枚数を設定
   - 統計 → 学習履歴 のタイトル行のアイコンで「学習量」と「目標達成」を切り替えられること、
     目標達成では達成した日と届かなかった日が色で分かれ、下に凡例が出ることを確認
   - 目標枚数を未設定に戻すと切替アイコンが消え、従来の学習量の表示になることを確認
4. バッジの獲得日
   - 統計 → 学習の記録 → バッジをタップ → グリッドの下に獲得日、または次に取れるバッジまでの
     残りが表示されることを確認。もう一度タップするか余白をタップすると閉じることを確認
5. HTML プレビューの window.open（Pro）
   - HTML のコードブロックにリンクか window.open を書いて実行し、全画面プレビューを開く
   - タップすると http(s) の URL が Safari で開くこと、それ以外の URL はプレビュー下部の
     コンソールに理由が1行出ることを確認
```
