## 日本語

```
キーボード操作を大きく広げ、コードの実行を途中で中止できるようにしたアップデートです。

【新機能・改善】
・コードの実行を途中で中止できるようになりました
・実行結果を、出力からエラーまで起きた順に表示するようになりました
・統計「評価別ランキング」（Pro）で、選んだカードから重点復習を始められるようになりました（行を右にスワイプして「ここから学習」）
・デッキの作成・編集画面を「基本」「読み上げ」「実行環境」の見出しで整理し、見やすくしました
・デッキ・タグ・カードの作成・編集画面の項目を枠にまとめ、左下に閉じるボタンを追加しました（ほかの画面の左下の戻るボタンと同じ位置です）
・アーカイブにしたデッキやカードは、編集画面のタイトルの横にアイコンが出るようになりました
・タグ管理でまとめて色を変えるとき、タグ編集と同じく、青・テーマの色・白黒も選べるようになりました
・コードのプレビューの切り替えボタンを押しやすくし、コピーボタンは押したことがはっきり分かるようにしました
・学習時間（回答時間）から、アプリを離れていた時間と、学習中にカードを編集していた時間を除くようにしました
・iPhone でも、画面上部のタイトル付近をタップすると一覧の先頭に戻るようになりました
・ハードウェアキーボード（iPad の Magic Keyboard など）で操作できる範囲を大きく広げました：設定の各画面、すべての確認ダイアログ、デッキ・タグ・カードの編集画面の各項目、コードブロックの言語選択・実行・プレビューをキーで操作できます。各画面で ? キーを押すと、使えるキーの一覧が表示されます

【不具合の修正】
・Python でエラーになると「PythonError」とだけ表示され、エラーより前に print した内容も消えていた不具合を修正
・iPad のウィンドウ表示（ステージマネージャなど）で、戻る・閉じるボタンがウィンドウ左上の操作ボタンに重なる不具合を修正
・iPad で、ショートカット一覧のボタンを押すと裏の一覧が先頭に戻ってしまう不具合を修正
・iPad で、通知設定のラベルを入力したあと、時刻や電池の表示が消えたままになる不具合を修正
・キーボードを出したまま入力画面を閉じると、次の画面の一覧が最下部を越えてスクロールできてしまうことがある不具合を修正
・統計「評価別ランキング」で表示を切り替えたとき、一瞬別の数字が表示される不具合を修正

その他、細かな文言と表示の調整を含みます。
```

## English

```
This update greatly expands keyboard control and lets you stop running code.

[ New & Improved ]
• You can now stop code while it is running
• Run results now appear in the order things happened, from output to errors
• In Stats → Grade Ranking (Pro), you can start a Focused Review from the card you choose (swipe a row right and tap "Study from here")
• The deck create and edit screen is now organized under Basics, Read Aloud and Runtime Setup headings for easier reading
• On the deck, tag and card create/edit screens, items are now grouped into panels, and a Close button has been added to the bottom left (the same spot as the Back button on other screens)
• An archived deck or card now shows an icon next to the title on its edit screen
• When changing the color of several tags at once in Tags, you can now also choose blue, the theme color, or black and white, just like when editing a tag
• The preview toggle for code is easier to tap, and copy buttons now show clearly that they were pressed
• Study time (response time) no longer includes time spent away from the app or editing a card during a study session
• On iPhone, tapping near the title at the top of a screen now scrolls the list back to the top
• Much more of the app now works with a hardware keyboard (such as the Magic Keyboard for iPad): every settings screen, all confirmation dialogs, each item on the deck, tag and card edit screens, and code block language selection, running and preview. Press ? on any screen to see its available keys

[ Bug fixes ]
• Fixed an issue where a Python error showed only "PythonError" and anything printed before the error was lost
• Fixed an issue on iPad in windowed mode (such as Stage Manager) where the Back and Close buttons overlapped the window controls in the top left
• Fixed an issue on iPad where tapping the keyboard shortcuts button scrolled the list behind it back to the top
• Fixed an issue on iPad where the time and battery indicators stayed hidden after entering a label in notification settings
• Fixed an issue where closing an input screen with the keyboard still open could let the list on the next screen scroll past its end
• Fixed an issue in Stats → Grade Ranking where a different number briefly appeared when switching the display

Also includes minor wording and display adjustments.
```

## 主なテスト手順
1. コード実行の中止
   - JavaScript のコードブロックに setTimeout(() => console.log('done'), 10000) などを書いて実行
   - 実行中に実行ボタンが赤い四角に変わり、押すと実行が止まって「実行を中止しました」と
     表示されること、途中までの出力が残ることを確認
2. 評価別ランキングからの重点復習（Pro）
   - 統計 → 評価別ランキング → 評価を選んでランキングを表示
   - 行を右にスワイプ →「ここから学習」で、そのカードから学習が始まることを確認
3. デッキ・タグ・カードの編集画面
   - 左下の閉じるボタンで画面を閉じられること（未保存の変更があれば確認が出ること）を確認
   - デッキの編集画面が「基本」「読み上げ」「実行環境」の見出しで区切られていることを確認
4. ハードウェアキーボード（任意・iPad と Magic Keyboard など）
   - 各画面で ? キーを押すとショートカット一覧が表示されることを確認
   - 設定の詳細画面で J/K で項目を移動し、Return で開く・Space でスイッチを切り替えられることを確認
   - 確認ダイアログで J/K でボタンを選び、Return で実行・Esc で閉じられることを確認
