## 主なテスト手順
1. 表示言語（中国語）
   - 設定 → 表示 → 表示言語 で「简体中文」「繁體中文」を選び、画面が切り替わることを確認
2. Python のスクレイピング練習（Pro）
   - デッキの編集 → 実行環境 → HTML/CSS 土台 で土台を追加し、名前を https://example.com/ に、
     中身に h1 タグで「Hello」という見出しを書いて保存
   - そのデッキのカードに Python ブロックを作り、次のコードを実行
       import requests
       from bs4 import BeautifulSoup
       res = requests.get("https://example.com/")
       print(BeautifulSoup(res.text, "html.parser").h1.text)
   - 「Hello」と出力され、結果の下に「実際の通信はしていません」と表示されることを確認
   - Python ブロックの「デッキのページ」を開き、URL の行をタップするとページの表示と HTML を確認できることを確認
3. ライブラリの自動読み込み
   - Python ブロックで「import numpy as np」「print(np.arange(3))」を「# pip:」なしで実行し、
     [0 1 2] と出力されることを確認
