## 主なテスト手順
1. 検索結果からの閲覧
   - ホーム画面右上の検索アイコン → 任意の文字で検索
   - 件数の行の右端の「閲覧」ボタンを押し、先頭のカードから閲覧モード（記録なし）で開くことを確認
   - 検索結果の行を右へスワイプして目のアイコンを押し、そのカードから開くことを確認
   - 学習画面の上部に、表示中のカードのデッキ名が出ることを確認
2. カード編集のプレビューの読み上げ
   - 任意のカードの編集画面 → 上部のモード切替で「プレビュー」にする
   - 左下のスピーカーボタンで、表示中の面が読み上げられることを確認
