## 日本語

```
どのタブからでも検索できるようにし、キーボード操作を整え、端末の容量を圧迫する不具合を修正したアップデートです。

【新機能・改善】
・学習・統計・設定タブの左上にも検索ボタンを追加しました（ホームと同じ位置）
・キーボードショートカットを追加しました。⌘F で検索、⌘N で新規作成、⌘W で閉じる・戻る、⇧E でアーカイブが、どの画面でも同じように使えます
・キーボードショートカット一覧を見やすく整理しました
・学習タイマーの休憩中に、何回目の休憩かを表示するようにしました（例：休憩中 (1/4)）

【不具合の修正】
・iCloud 同期やエクスポートで使った一時ファイルが端末に溜まり続け、容量を圧迫する不具合を修正（起動時に自動で片付けます）
・学習タイマーの休憩中にアプリを閉じると、翌日にリセットされず前日の続きから始まる不具合を修正
・入力中にボタンから一覧やシートを開くと、キーボード操作が効かない不具合を修正。閉じると入力していた位置にカーソルが戻るようになりました

その他、細かな文言と表示の調整を含みます。
```

## English

```
This update adds search to every tab, refines keyboard control, and fixes an issue that kept using up storage on your device.

[ New & Improved ]
• Added a search button to the top left of the Study, Stats and Settings tabs (same place as on Home)
• Added keyboard shortcuts that work the same on every screen: ⌘F to search, ⌘N to create, ⌘W to close or go back, and ⇧E to archive
• Reorganized the keyboard shortcuts list to make it easier to read
• During a study timer break, the timer now shows which break you are on (for example, On break (1/4))

[ Bug fixes ]
• Fixed an issue where temporary files from iCloud sync and export kept piling up and used up storage (they are now cleaned up automatically at launch)
• Fixed an issue where closing the app during a study timer break made the timer continue from the previous day instead of resetting the next day
• Fixed an issue where, if you tapped a button to open a list or sheet while typing, keyboard shortcuts did not work in it. When you close it, the cursor now returns to where you were typing

Also includes minor wording and display adjustments.
```

## 主なテスト手順
1. 各タブからの検索
   - 学習・統計・設定タブの画面左上の検索アイコンを押し、カード検索画面が開くことを確認
   - 検索画面を閉じると、開いたタブに戻ることを確認
2. 一時ファイルの片付け（端末の容量）
   - 設定 → データ管理 → 「バックアップ」で JSON を書き出し、共有シートを閉じる
   - アプリを再起動しても、通常どおり起動・動作することを確認
