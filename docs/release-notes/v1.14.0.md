## 主なテスト手順
1. iPhone Duo での表示
   - 閉じた状態でアプリを起動し、タブが画面右側の縦の帯の中に表示されることを確認
   - 端末を開く・閉じる・横向きにするたびに、画面いっぱいに表示が合うことを確認
2. 通常の iPhone / iPad
   - ホーム → デッキ → 学習の流れで、これまでどおり動作することを確認
