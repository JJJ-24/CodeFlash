# v1.3.0 リリースノート

App Store Connect の「このバージョンの新機能」欄に貼り付け用。

---

## 日本語

```
Pro版を追加しました！

【新機能】
・ Pro版（買い切り）を追加
・ 詳細な学習統計：月別グラフ・苦手カードランキング・カード別評価推移（Pro）
・ FSRSスケジューリングの詳細調整（Pro）
・ 学習完了画面・グレード別ランキングに平均回答時間を表示
・ 利用規約と「アプリについて」を設定画面に追加

【主な改善】
・ 鉛筆アイコンをタップした際に対象アイテムにフォーカスするように改善
・ バックアップに各種設定値も含めるよう拡張
・ iPadのレイアウト調整（アイコン間隔・月別グラフの横幅）

【主な修正】
・ 学習タブ初回マウント時にキーボードショートカットが効かない不具合を修正

その他、細かなUIの改善や不具合の修正を含みます。
```
