```
## v1.3.0 で追加：Pro 機能（買い切り課金）について

このバージョンで Pro 版（買い切り課金）を新たに導入しました。

### Pro 機能のテスト手順
1. アプリを起動 → 「設定」タブを開く
2. 「Proにアップグレード」ボタンをタップしてペイウォール画面を開く
3. 購入ボタンから Sandbox 購入を実行
4. 購入完了後、以下の Pro 機能が解放されることを確認:
   - 「統計」タブ → 月別学習グラフ、苦手カードランキング、カード別統計シート
   - 「設定」タブ → FSRS カスタマイズ（リクエストレート・最大学習間隔など）
5. 既存購入の復元: ペイウォール下部の「購入を復元」ボタンで動作確認

### Sandbox テスト用 Apple ID
ID: __SANDBOX_TESTER_EMAIL__
Password: __SANDBOX_TESTER_PASSWORD__

### 補足
- 課金は RevenueCat 経由で処理されます
- ユーザー登録・サーバー側のアカウント管理はなし
- データはすべて端末ローカル（SQLite）に保存
```
