## 日本語

```
苦手カードの分析と復習がさらに便利になりました。

【新機能】
・ 苦手カードランキングに「重点復習」ボタンを追加：上位カードだけを集中的に学習できます（Pro）
・ ランキングに「平均回答時間」モードを追加：時間がかかっているカードを抽出できます（Pro）
・ ランキングに期間フィルターとデッキ絞り込みを追加（Pro）

【主な改善】
・ カード編集のプレビューモードを学習画面に近い見た目に刷新（読み取り専用化）
・ カード一覧・タグカード一覧の統計アイコンタップで対象カードにフォーカス
・ アプリアイコンを刷新（iOS 18 のダーク／Tintedモードにも対応）

【主な修正】
・ カード編集でブロック編集中にモードを切り替えるとショートカットキーが効かなくなる問題を修正
・ カード一覧プレビューを上から順に最初の内容ブロックが表示されるよう修正
・ カード一覧プレビューで空のコード／画像ブロックがスキップされるよう修正

その他、細かなUIの改善や不具合の修正を含みます。
```

## v1.4.0 の変更点

主な変更は既存の Pro 機能「苦手カードランキング（詳細統計）」の拡張です。
新規の課金商品やサブスクリプションは追加していません（Pro は v1.3.0 で承認済み）。

### 新機能のテスト手順（既存 Pro ユーザー想定）
1. アプリを起動 → 「統計」タブを開く
2. 既に Pro 購入済みであることを確認（未購入の場合は「購入を復元」または Sandbox 購入）
3. 統計タブ下部の「苦手カードランキング」で以下を確認:
   - 「重点復習」ボタン → ランキング上位カードのみで学習セッションが開始される
   - ランキングモード切替（評価回数 / 平均回答時間）
   - 期間フィルター（今日 / 7日 / 30日 / 全期間）
   - デッキ絞り込み
4. アプリアイコンが iOS 18 のダーク／Tinted モードに対応していることを確認
   （ホーム画面の外観モード切替で確認可）

### Sandbox テスト用 Apple ID（既存購入の検証用）
ID: __SANDBOX_TESTER_EMAIL__
Password: __SANDBOX_TESTER_PASSWORD__

### 補足
- 課金は RevenueCat 経由で処理されます（v1.3.0 から変更なし）
- ユーザー登録・サーバー側のアカウント管理はなし
- データはすべて端末ローカル（SQLite）に保存
