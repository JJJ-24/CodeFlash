## v1.5.0 の変更点

主な新機能は iCloud 同期（Pro）です。新規の課金商品・サブスクリプションは追加していません
（Pro は v1.3.0 で承認済みの「買い切り1商品」のまま）。iCloud 同期・配色（カラーテーマ）は既存 Pro の追加機能です。

### iCloud 同期のデータ取り扱い
- ユーザー自身の iCloud（iCloud Drive のアプリ専用コンテナ）にデータを保存・同期します。
- 当社サーバーや第三者へは一切送信しません。アカウント登録もありません。
- 同期対象：デッキ・カード・タグ・学習履歴・カード画像。
- 端末ローカルの SQLite が正本で、iCloud は同期／バックアップ用です。

### 新機能のテスト手順（既存 Pro ユーザー想定）
1. 端末が iCloud にサインインしていることを確認（設定アプリ → Apple ID → iCloud → iCloud Drive オン）
2. アプリ → 「設定」タブ → 「iCloud 同期」
   - Pro 購入済みであることを確認（未購入の場合は「購入を復元」または Sandbox 購入）
   - 「iCloud 同期」をオンにする → 「今すぐ同期」をタップ → 「最終同期」時刻が更新されることを確認
   - （2台で確認できる場合）同じ Apple ID の別端末でも同期をオンにし、一方の変更が他方へ反映されることを確認
3. デッキを編集 → アイコン・カラーを設定（無料機能）
4. 「設定」→「表示」→「配色」を変更（8種類。「ペーパー」は無料、ほかは Pro。カードと画面全体の背景に反映）

### Sandbox テスト用 Apple ID（既存購入の検証用）
ID: __SANDBOX_TESTER_EMAIL__
Password: __SANDBOX_TESTER_PASSWORD__

### 補足
- 課金は RevenueCat 経由で処理されます（v1.3.0 から変更なし、新規 IAP 商品なし）。
- ユーザー登録・サーバー側のアカウント管理はなし。
- データは端末ローカル（SQLite）と、ユーザー自身の iCloud にのみ保存されます。
