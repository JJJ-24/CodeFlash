## v1.6.0 の変更点

主な変更は詳細統計グラフの刷新・カード検索強化・SQL/C++コード実行追加（Pro）・高度な通知リマインダーです。
新規の課金商品・サブスクリプションは追加していません（Pro は v1.3.0 で承認済みの「買い切り1商品」のまま）。
SQL/C++ 実行は既存 Pro の追加機能です。

### C++ 実行（Wandbox API）について
- C++ コードブロックの実行時のみ、Wandbox API（https://wandbox.org/）に HTTP リクエストを送ります。
- 送信内容はユーザーが入力したソースコードのみです。アカウント情報・個人情報は一切含みません。
- Wandbox は無料のパブリック API サービスです。

### 新機能のテスト手順（既存 Pro ユーザー想定）
1. **SQL / C++ 実行**
   - カード編集画面でコードブロックを追加 → 言語を「SQL」または「C++」に設定 → コードを入力して実行ボタンをタップ
   - 未購入の場合はペイウォール画面が表示される（「購入を復元」または Sandbox 購入）
2. **高度な通知リマインダー**
   - 「設定」タブ → 「通知」→ スケジュールを複数追加 → 曜日ごとにオン/オフを設定 → 通知文に due 枚数が含まれることを確認
3. **言語切替**
   - 「設定」タブ → 「表示」→「言語」→ English に変更 → 全画面が英語表示になることを確認
4. **月別グラフ**
   - 「統計」タブ → 「詳細統計（Pro）」→ 月別グラフの各バーをタップ → ドーナツグラフが表示されることを確認
5. **カード検索フィルター**
   - ホーム画面の検索アイコン → 検索結果画面でデッキ・タグ絞り込みを複数選択して検索
