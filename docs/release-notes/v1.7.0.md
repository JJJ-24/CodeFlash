## 日本語

```
デッキ・カードをアーカイブできるようになりました。

【新機能】
・ アーカイブ：デッキ・カードを学習対象や統計から除外できるように。一覧の左スワイプからもアーカイブ/解除が可能（過去の学習履歴は残ります）

・ コードブロックの言語選択モーダルで、選択中の言語へ自動スクロール
・ コード実行結果・表示の横スクロール対応を強化
・ iCloud同期：別端末の新しいデータで上書きされた際に通知モーダルで知らせるように（誤発火の修正含む）。同期画面のデータ復元まわりを整理

その他、細かなUIの改善や不具合の修正を含みます。
```

```
## v1.7.0 の変更点

主な変更はデッキ・カードのアーカイブ、デッキ配色のテーマ追従、SQL初期化SQL（Pro）、
学習画面の前後送りボタン、配色まわりの改善です。
新規の課金商品・サブスクリプションは追加していません（Pro は v1.3.0 で承認済みの「買い切り1商品」のまま）。
SQL の初期化SQL は既存 Pro の追加機能で、すべてデバイス内（sql.js）で完結し、新たな外部通信はありません。

### 新機能のテスト手順
1. **アーカイブ**
   - ホーム画面でデッキを左スワイプ →「アーカイブ」をタップ → 学習タブ・統計から除外されることを確認（カード一覧でも同様に左スワイプ可能）
   - アーカイブ済みは一覧でグレー表示。再度左スワイプで解除できる
2. **デッキカラー「配色テーマ追従」**
   - デッキ編集 → カラー選択で「配色テーマ追従」を選択 → アプリの配色テーマに追従することを確認
3. **連続学習のサプライズアイコン**
   - 学習を継続するとストリーク日数に応じてアイコンが変化することを確認
4. **学習画面の前後送りボタン**
   - 学習画面（表面・全画面）で左右下のフローティングボタンから次/前のカードへ送れることを確認
5. **初期化SQL（既存 Pro ユーザー想定）**
   - デッキ編集で初期化SQL（共通スキーマ・初期データ）を設定 → SQLブロック実行時に反映されることを確認
   - 未購入の場合はペイウォール画面が表示される（「購入を復元」または Sandbox 購入）
```
