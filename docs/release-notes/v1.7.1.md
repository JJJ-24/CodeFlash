## v1.7.1 の変更点
主な変更はタグのカード一覧の選択モード・フィルター、タグ色の「配色テーマ追従／白黒」、
デッキ・タグ色ピッカーへのプライマリーカラー追加、ドラッグ並べ替えとキーボード固着の不具合修正です。
新たな外部通信・新規 IAP はありません。

### 主なテスト手順
1. **タグのカード一覧（選択モード）**
   - タグ管理 → タグを開く → 右上の選択ボタン → カードを複数選択 →「タグを外す」「アーカイブ切替」が機能することを確認
   - 「すべて／有効」フィルターでアーカイブ済みカードの表示/非表示が切り替わることを確認
2. **タグの色**
   - タグ編集 → 「配色テーマ追従」「白黒」を選択 → 配色テーマやライト/ダークに応じて色が変わることを確認
3. **色ピッカーの既定色**
   - デッキ／タグ新規作成で先頭のプライマリーカラー（青）が既定選択になっていることを確認
4. **ドラッグ並べ替え**
   - 一覧を長押しドラッグで上下に大きく動かしても、掴んだカードが消えず、上下方向ともスクロールすることを確認
